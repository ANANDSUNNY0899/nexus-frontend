##  Overview

This is the official frontend for **Nexus Gateway**. It provides a real-time dashboard for developers to manage their API keys, monitor traffic analytics, and visualize cost savings.

It connects to the Go/Redis backend to display live data and handles user authentication via API Key generation.

---

##  Features

*   ** Cyberpunk UI:** Glassmorphism design with a responsive dark mode layout using **Tailwind CSS**.
*   ** Real-Time Analytics:** Interactive charts powered by **Recharts** to visualize traffic spikes and cache hits.
*   ** Live Streaming:** Simulates ChatGPT-style streaming responses using the TextDecoder API.
*   ** Billing Integration:** Seamless UI for **Stripe Checkout** to handle plan upgrades.
*   ** Integrated Docs:** Built-in documentation page for easy developer onboarding.

##  Getting Started Locally

### 1. Clone the Repo
```bash
git clone https://github.com/ANANDSUNNY0899/nexus-frontend.git
cd nexus-frontend
```
### 2. Install Dependencies
```bash
npm install
```
### 3. Run Development Server
```bash
npm run dev
```

Open http://localhost:3000 with your browser to see the result.


## Tech Stack

    Framework: Next.js 14 (App Router)
    Styling: Tailwind CSS
    Language: TypeScript
    Charts: Recharts
    Deployment: Vercel
